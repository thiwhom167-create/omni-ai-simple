คลาวด์ส่วนตัว
ของคุณ

เป้าหมายคือพื้นที่ไฟล์ออนไลน์ที่เข้าถึงได้จากมือถือและคอมพิวเตอร์ ไม่ใช่แค่ไฟล์ที่เก็บอยู่ในเบราว์เซอร์เครื่องเดียว

☁
สถานะ: ยังไม่พร้อมเก็บไฟล์จริงหน้าเว็บปัจจุบันยังไม่มี API สำหรับอัปโหลดไฟล์ ไม่มีพื้นที่เก็บข้อมูลถาวรที่เชื่อมอยู่ และไม่มีระบบสิทธิ์ไฟล์ จึงยังไม่ควรใช้เก็บไฟล์สำคัญ

ส่วนประกอบที่จำเป็น

ระบบจะทำงานจริงได้เมื่อเชื่อมต่อครบ

📦
พื้นที่เก็บไฟล์ถาวรใช้ object storage หรือดิสก์ถาวรที่เหมาะกับขนาดไฟล์ พร้อมกำหนดโควตาและข้อจำกัดการอัปโหลด
🔐
สิทธิ์การเข้าถึงไฟล์ตรวจสอบว่าผู้ใช้เป็นเจ้าของไฟล์ก่อนดู ดาวน์โหลด เปลี่ยนชื่อ หรือลบข้อมูล
🔎
รายการไฟล์และค้นหาจัดเก็บชื่อ ขนาด ประเภทไฟล์ วันที่สร้าง และตำแหน่งไฟล์ในฐานข้อมูล
⟲
สำรองและกู้คืนแยกชุดสำรองออกจากพื้นที่ใช้งานหลัก และทดสอบการกู้คืนเป็นระยะ

ขอบเขตการใช้งาน

ออกแบบสำหรับอุปกรณ์หลายเครื่อง

จากมือถือหรือคอมพิวเตอร์

เข้าสู่ระบบจากเบราว์เซอร์ แล้วเข้าถึงไฟล์ชุดเดียวกันผ่านเซิร์ฟเวอร์กลาง ไม่ใช่เก็บไฟล์แยกไว้ในแต่ละอุปกรณ์

ข้อมูลที่ยังต้องมี

IDENTITY & ACCESS

บัญชีผู้ใช้
และสิทธิ์การเข้าถึง

บัญชีผู้ใช้ต้องเป็นระบบจริงที่ตรวจสอบตัวตนและปกป้องข้อมูลของแต่ละคนแยกจากกัน

♙
สถานะ: ยังไม่เปิดใช้งานเว็บไซต์ปัจจุบันยังไม่มีการสมัครสมาชิกหรือเข้าสู่ระบบ และยังไม่มีฐานข้อมูลสำหรับบัญชี ไม่ควรใส่ข้อมูลส่วนตัวหรือรหัสผ่านลงในแชตเพื่อใช้แทนระบบบัญชี
1
สมัครและเข้าสู่ระบบตรวจสอบข้อมูลผู้ใช้และใช้ session หรือ token ที่มีอายุเหมาะสม
2
รหัสผ่านปลอดภัยเก็บเฉพาะค่า hash ที่เหมาะสม ไม่เก็บรหัสผ่านเป็นข้อความธรรมดา และห้ามส่ง secret กลับไปยังหน้าเว็บ
3
แยกข้อมูลรายบัญชีตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ทุกครั้งสำหรับไฟล์ ประวัติ และการตั้งค่าของผู้ใช้
4
การกู้คืนบัญชีและบันทึกเหตุการณ์มีวิธีเปลี่ยนรหัสผ่าน และบันทึกเหตุการณ์ด้านความปลอดภัยโดยไม่เก็บข้อมูลลับเกินจำเป็น
BACKUP & RECOVERY

สำรองข้อมูล
และกู้คืน

การสำรองข้อมูลต้องทำอัตโนมัติ ตรวจสอบได้ และกู้คืนได้จริง ไม่ใช่เพียงปุ่มดาวน์โหลดที่หน้าเว็บ

⟲
สถานะ: ยังไม่มีการสำรองข้อมูลอัตโนมัติตอนนี้ยังไม่มีระบบจัดเก็บไฟล์หรือฐานข้อมูลของผู้ใช้ที่เชื่อมกับงานสำรองข้อมูล อย่าใช้เว็บไซต์นี้เป็นสำเนาเดียวของไฟล์สำคัญ
01
สำรองฐานข้อมูล

ตั้งเวลาสำรองข้อมูลบัญชี ประวัติ และ metadata พร้อมกำหนดระยะเวลาเก็บรักษา

02
สำรองไฟล์แยกจากระบบหลัก

ใช้พื้นที่สำรองอีกชุดหนึ่งที่ไม่ถูกลบพร้อมกับไฟล์ใช้งานหลัก

03
ตรวจผลการสำรอง

บันทึกผลสำเร็จ/ล้มเหลว แจ้งเตือนเมื่อผิดพลาด และอย่าสมมติว่าการสำรองเสร็จเพียงเพราะงานเริ่มทำงาน

04
ทดสอบการกู้คืน

ทดลองกู้คืนชุดสำรองเป็นระยะ เพื่อยืนยันว่าข้อมูลนำกลับมาใช้ได้จริง
